# 사용 흐름과 확인 범위

| 역할 | 업무 | 시연 또는 화면 |
| --- | --- | --- |
| 관객 | QR 참여 → 원하는 채널 고르기 → 다음 소리·정지·재개 | 대표 GIF. 음악·라디오는 보존하고 공간음만 조작 |
| 운영자 | 관리자 진입 → 현장/테스트 PC 선택 → 인증 → 이 PC를 재생기로 연결 → 전체 정지 | 별도 관리자 시나리오 |
| 운영자 | QR 공유, 참여 열기/닫기, 채널·전체 음량 | 관리자 화면과 배포 구조. 참여와 출력 제어는 다른 동작 |
| 운영자 | 준비 문제 확인, 파일 복구, 채널별 부분 운영 | 운영 문서와 인터랙션 구조. 권한·운영 데이터에 접근하지 않음 |
