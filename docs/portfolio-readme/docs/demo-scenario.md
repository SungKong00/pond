# Pond 관객 시연 설계

## 상황

도서관 전시에서 운영자가 이미 한 대의 PC로 음악·라디오·공간음을 재생하고 있다. 방문객은 전시 옆 QR로 자신의 휴대폰을 리모컨처럼 열고, 전시에 흐르는 음악과 라디오는 그대로 두면서 공간음만 바꿔 보고 싶다.

## 시연 순서

| 장면 | 관객 행동 | 화면에서 확인할 것 |
| --- | --- | --- |
| 1. 참여 | 공개 첫 화면을 보고 현장 QR로 참여 | QR 안내 화면에서 세 카드가 활성화된 모바일 화면으로 전환. 공개 첫 화면과 로컬 룸 참여를 연속 캡처하고 참여 코드는 노출하지 않는다. |
| 2. 변경 | 공간 카드의 오른쪽 ‘다음 소리’를 누름 | 깊은 바다 → 변경 중 → 비와 천둥. 요청 접수와 결과 확정을 구분해 보여준다. |
| 3. 정지 | 공간 카드의 왼쪽 재생·정지 버튼을 누름 | 공간음만 정지. 공간의 다음 소리는 잠기고 음악·라디오는 재생 중으로 남는다. |
| 4. 재개 | 같은 공간 카드의 왼쪽 버튼을 다시 누름 | 공간음이 같은 ‘비와 천둥’으로 돌아온다. 다른 채널은 그대로다. |

## 촬영 기준

- 휴대폰 한 화면에 카드 세 개와 버튼 여섯 개를 모두 넣는다. 실제 배포본 UI와 WebGL 그래픽을 사용한다.
- 누를 때와 결과가 확정됐을 때를 각각 읽을 수 있게 잡는다. 상태가 바뀌는 순간을 편집으로 대신하지 않는다. 주소 전환은 실제 참여 요청을 발생시키고 QR을 카메라로 읽는 장면은 담지 않는다.
- 공개 첫 화면에는 테스트 상태를 넣지 않는다. 참여 후 결과는 분리된 로컬 테스트 룸이 응답한다. 실제 관객 링크, 전시 PC와 스피커, 운영용 음원은 사용하지 않는다.
- GIF는 요청과 결과가 화면에서 어떻게 구분되는지 보여준다. 브라우저 녹화에서 264프레임을 10.56초(25fps)로 내보냈다. 세부 프레임·상태 검증은 QA 기록에 있다.
